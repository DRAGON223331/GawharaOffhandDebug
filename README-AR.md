# GawharaOffhandDebug

بلجن تشخيص: بيقولك مين البلجن اللي بيلغي الـ offhand (زرار F أو حط شيلد في خانة اليد التانية).

1. ارفع محتوى الفولدر على GitHub (زي ما عملت مع باقي البلجنات) وخلي الـ Action يبني الـ JAR.
2. حط الـ JAR في plugins وريستارت.
3. اكتب `/offhanddebug` لتشوف البلجنات اللي سامعة الحدث.
4. دوس F أو جرّب تحط شيلد في اليد التانية. لو حد لغاها هتظهر لك رسالة حمرا (للأدمن) ويتكتب في اللوج: "CANCELLED ... by one of: <أسماء البلجنات>".
5. ابعتلي السطر ده.

النسخة 1.1.0: بتحدد الفترة اللي اتلغى فيها الحدث وبتكتب البلجنات اللي بتشتغل في الفترة دي بالترتيب (غالباً بلجن أو اتنين)، وبتتابع كمان سحب الأيتم (drag) لخانة اليد التانية.
لو كتب "none" يبقى مفيش بلجن لسه سامع في الفترة دي، والإلغاء من Paper نفسه أو من بلجن بيشتغل على مستوى الـ packets (ProtocolLib / PacketEvents).

بعد ما نعرف المشكلة امسح البلجن.
